# Flow

- During authentication flow, user can choose either github based or database based flow. Pricing varies based on chosen plan.
- If user selects github then, github is single source of truth. Content will be stored in github and local filesystem
- If user selects database then, all contents of will be stored in realtime database and local filesystem

**Current Implementation**

- Now, It properly handles the github flow to save files.
- Have to modify it to handle alternate realtime db flow.
